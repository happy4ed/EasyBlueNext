# EasyBlue Next

Windows용 EasyBlue 동글 제어 앱을 .NET10/WPF로 다시 작성한 프로젝트입니다. 현재 하드웨어 지원 대상은 VID1D54/PIDB002이며, 원본 EBTiny.exe/KMHook.dll 없이 실행합니다.

## 설치

GitHub Releases의 `EasyBlue-Next-0.3.5-Setup.exe`를 실행하세요. 관리자 권한 없이 현재 사용자에게 설치합니다. 시작 메뉴, 앱 제거, 선택적 바탕화면 바로 가기와 Windows 시작 시 트레이 실행을 지원합니다. 업데이트 설치는 기존 앱에 종료를 요청합니다. 0.3.1 이하 최초 업데이트는 진행 중 장치 작업을 마친 뒤 이전 프로세스 종료를 확인하세요.

## 기능

- 다중 모니터와 폰·태블릿의 물리 크기 기준 배치, 붙은 경계에서 대기 후 자동 전환
- PC 화면 양방향 카운트다운/진행 막대와 브리딩 효과
- 기기별 사용자 단축키 및 PC↔마지막 기기 공유 단축키
- 페어링/PIN, 저장 기기 연결/삭제, 표시 이름/화면 크기 설정
- 실제 동글 Bluetooth 이름 읽기/변경, 원본 저장 페이지 백업 및 쓰기 후 검증
- LED, 마우스 속도/가속·스크롤 배율, 한/영 전송, 시작 시 실행
- 라이트·다크·시스템 테마, 얇은 스크롤바, 전체 기기 관리 페이지 스크롤, 트레이 기기 전환
- 사용자 시작프로그램 폴더 바로가기와 상태 확인·복구, 업데이트 종료 요청
- 특수키 그룹·클립보드 설정, 진단 시작·종료, 연결 상태 토스트

## 검증 범위

현재 코어 검사183개, Windows 크로스 빌드, NSIS 컴파일과 설치 아카이브 검증을 수행했습니다. 사용자에게서 기존 버전의 입력 전환 동작 확인을 받았으나, 새 페어링·동글 EEPROM 이름 변경과 Windows 설치·제거/시작 프로그램은 이 Linux 빌드 환경에서 실제로 실행하지 못했습니다. 출시물은 사전 검증용 준비본입니다.

특수키 4개 그룹과 US/한국어 두벌식 PC 클립보드 전송은 새 입력 설정에서 지원합니다. 원본 사용자 키맵 파일 가져오기, 프랑스/독일 배열과 일부 OS별 예외는 남아 있습니다. 자세한 대조 목록은 [원본 설정 목록](Notes/Original-settings-inventory.md), [0.3.0 변경 사항](Notes/0.3.0-changes.md), [통신 분석](Notes/0.2.2-protocol-audit.md)에 있습니다.

## Windows에서 빌드

.NET10 SDK와 NSIS3 Unicode 컴파일러(`makensis`가 PATH에 필요)를 준비합니다.

```powershell
./Build-Windows.ps1
./Installer/Build-Installer.ps1
```

포터블 출력: `artifacts/win-x64`. 설치 EXE는 상위 폴더에 생성됩니다. 개발 중 코어 검사만 실행하려면:

```powershell
dotnet run --project EasyBlue.Checks -c Release
```

## 데이터

설정: `%LOCALAPPDATA%/EasyBlueNext/preferences.json`. 동글 이름 변경 전 백업: 같은 폴더의 `Backups`. 제거 시 사용자 설정과 백업은 남깁니다. 저장된 이름은 영문·숫자·기호 최대31자를 지원하며, 휴대폰에 캐시된 기존 Bluetooth 이름은 별도로 갱신해야 할 수 있습니다.

이 저장소에는 원본 EXE/DLL/펌웨어, 실제 사용자 설정 또는 동글 백업을 포함하지 않습니다. `Notes`에는 재현과 검토를 위한 정적 분석 근거와 이식 범위를 기록했습니다.

### 0.3.1
트레이 우클릭 메뉴에서 기기별 연결과 입력 전환을 실행할 수 있습니다. 사용자 지정 이름, 연결 상태, 단축키가 표시됩니다. 실제 Windows 및 기기 확인은 필요합니다.

### 0.3.2

로그인 시 현재 사용자 예약 작업으로 실행하며, 상태 확인·복구와 설치/제거 처리를 통합했습니다. 배터리·네트워크 조건에 제한하지 않으며 비정상 종료 시 최대 3회 재시도합니다. 업데이트 시 실행 중인 앱에 정상 종료를 요청합니다. 0.3.1 이하 최초 업데이트는 작업 완료 확인 후 이전 프로세스를 종료합니다.

얇고 둥근 테마별 스크롤바, 명시적인 진단 시작/종료, 4개 특수키 그룹, US/한국어 두벌식 클립보드 전송을 추가했습니다. 특수키·클립보드 설정은 입력 설정에서 사용할 수 있습니다. 클립보드의 이모지·이미지·서식과 프랑스/독일 배열은 지원하지 않습니다. 연결 중/성공/실패 토스트와 전체 전환 10초 제한을 적용했습니다. 기존 경계 자동 전환 판정은 유지했습니다.

코어 검사 182개 및 Microsoft 작업 스케줄러 XSD 검증을 통과했습니다. 실제 Windows 로그인, 설치/업데이트/제거와 Bluetooth 입력은 현장 확인이 필요합니다. 자세한 변경과 한계는 [릴리스 노트](Notes/0.3.2-changes.md)를 참조하세요.

### 0.3.3

예약 작업 등록 재확인 실패 보고에 따라 새 예약 작업 생성을 제거했습니다. 사용자 시작프로그램 폴더 바로가기를 등록하고 실행 경로·옵션·작업 폴더를 다시 읽어 검증합니다. 이전 예약 작업과 Run 항목은 새 등록을 확인한 뒤 정리합니다. Windows 시작 앱 설정을 여는 버튼을 제공합니다.

연결 토스트는 활성 모니터 오른쪽 아래 최상위 창으로 표시합니다. 연결 중 최소0.7초, 성공2.6초, 실패6초이며 실제 입력 전환을 지연하지 않습니다. 코어 검사176개 통과. 실제 Windows 자동실행과 UI는 현장 확인이 필요합니다. [변경 사항](Notes/0.3.3-changes.md).

### 0.3.4

클립보드·특수키·기기 선택의 드롭다운을 펼친 목록까지 라이트·다크 테마로 통일했습니다. 초기 USB 검색 후 입력 엔진에 세션을 연결하고 PC 가장자리 감시를 준비합니다. Bluetooth 미연결 상태에서도 로컬 감시부터 준비하며 실제 전환 전의 원격 키 해제 확인은 유지합니다. 감시 준비가 실패하면 5초 뒤 재준비하며, 진단을 켠 동안 준비 상태와 자동 전환 중단 이유를 기록합니다.

코어 검사183개, Windows용 빌드, 테마별 색상 대비 계산 및 패키지 검증을 수행했습니다. 최초 실행 자동 전환 증상을 이 Linux 환경에서 실제 재현한 것은 아닙니다. 실제 Windows에서 앱 재시작 직후 경계 전환과 펼친 목록을 확인해야 합니다. [변경 사항](Notes/0.3.4-changes.md).

## 0.3.5 UI 마무리

왼쪽 메뉴 네 개의 아이콘 크기와 열을 통일하고 포커스 시 위치 변화를 없앴습니다. 페어링 버튼은 테마별 글자색을 명시하며, 상태 문구와 배치 이름까지 최소12 DIP를 적용합니다. 자동 전환과 통신 동작은 그대로 유지합니다. [변경 사항](Notes/0.3.5-changes.md).
