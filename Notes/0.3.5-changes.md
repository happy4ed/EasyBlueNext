# EasyBlue Next 0.3.5

- 왼쪽 메뉴 네 개 모두 동일한 16×16 벡터 아이콘, 20px 아이콘 열, 8px 간격과 42px 최소 행 높이를 사용합니다. 선택과 키보드 포커스에도 글자 위치가 변하지 않습니다.
- 새 기기 페어링 버튼은 밝은 글자색을 명시하고 라이트/다크 테마 모두 대비 5:1 이상의 파란 배경을 사용합니다. 고대비 모드는 Windows 색상을 따릅니다.
- 작은 상태 문구, 기기 정보, 모니터 배치 이름까지 최소 글자 크기 12 DIP로 높였습니다. 기본 창 크기와 기본 본문 13 DIP는 유지합니다.
- 자동 전환 및 장치 통신 코드는 변경하지 않았습니다.

검증: Windows x64 WPF 게시 빌드와 배포 파일 검증. 이 환경에서는 Windows 화면을 직접 실행하지 못했습니다.
