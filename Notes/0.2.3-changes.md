# 0.2.3: 자동 전환 및 단축키와 대기 안내

- PC 복귀/마지막 기기에 같은 키를 허용한다. 입력을 원격 기기로 캡처 중이면 PC 복귀, PC 상태이면 마지막 기기 연결로 해석한다. 키 반복은 무시한다.
- 고정 Ctrl+Alt+1~4 처리를 제거했다. 기기 관리 각 행에서 키 조합을 지정/해제하고 저장한다. 기기 주소 기반 ID와 연결하므로 등록 순서가 달라져도 대상이 유지된다. 전역/다른 기기와의 충돌을 검사한다. Ctrl/Alt/Win 조합과 F1~F24를 허용한다.
- 페어링 오류/취소 후 일시 중지를 사용자가 자동 전환을 다시 켜서 해제할 수 있다. 백그라운드 조회와 전환 작업을 구분해 조회 중에도 커서 영역 이탈/재진입과 대기 시간을 추적하고 조회 완료 후 전환한다.
- 물리 커서 좌표를 사용하고 모니터 영역의 끝 픽셀을 서로 중복 판정하지 않는다.4px 경계 감지와 화면 표시 크기 기준 스냅을 적용했다. 자동 경로 유무/일시 중지 상태를 화면에 표시한다. 경계 감지와 대기 완료를 진단에 남긴다.
- PC→기기와 기기→PC 경계 대기 시 PC 화면에 남은 시간/대상과 진행 막대를 표시한다.0.65초 주기의 불투명도 브리딩 효과. 클릭 통과/비활성화 스타일과 포커스 비수신을 적용했다. 영역 이탈/작업 중/전환 시 숨긴다. 폰→PC 경로는 실제 PC 모니터의 연결 경계에 표시한다. 휴대폰 화면 오버레이 기능은 없다.
- 핵심 검사143개 통과. 공유 단축키 양방향, 개별 ID 라우팅/영속 저장,4방향/음수 좌표/고해상도 경계, 대기 종료 및 취소, 조회 중 대기/영역 이탈을 검사했다. WPF와 native hook/overlay/실제 동글 실행은 이 Linux 환경에서 검증하지 못했다. 따라서 사용자가 보고한 자동 전환 불능의 모든 원인이 해결되었다고 단정하지 않는다.
- 0.2.2 통신 초기화 수정과 분석 근거는 유지한다.
