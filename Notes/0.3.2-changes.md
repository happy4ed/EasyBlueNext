# EasyBlue Next 0.3.2 — 자동실행 개선

기존 HKCU Run 대신 현재 사용자 SID 전용 예약 작업을 등록합니다. 로그인 10초 후 --background로 트레이에서 실행하며, InteractiveToken / LeastPrivilege로 비밀번호나 관리자 권한을 요구하지 않습니다. 배터리·네트워크·유휴 여부에 실행을 제한하지 않고 72시간 기본 제한을 해제합니다. 중복 실행은 무시하고 비정상 종료 시 1분 간격으로 최대 3회 재시도합니다. 사용자가 트레이에서 정상 종료하면 재시도하지 않습니다.

설치, 일반 설정, 제거가 동일한 등록 코드와 확인 절차를 사용합니다. 이전 EasyBlueNext Run 항목은 새 예약 작업 등록을 확인한 다음 제거합니다. 기존 EBTiny의 등록은 변경하지 않습니다. 앱에서 비활성화된 예약 작업을 자동으로 다시 활성화하지 않으며, 사용자가 등록·복구를 누르면 현재 실행 경로로 명시적으로 갱신합니다. 다른 경로에서 실행한 포터블 복사본으로 예약 작업 경로를 자동 변경하지 않습니다.

로그인 직후 USB가 준비되지 않았거나 연결이 끊긴 경우 10초 간격으로 재검색합니다. 페어링 실패 후 중단 상태와 기존 앱으로 제어를 넘긴 상태에서는 재검색하지 않습니다. 재검색은 페어링 요청이나 휴대폰 입력 전환을 자동으로 실행하지 않습니다.

일반 설정에서 실제 등록 상태와 최근 예약 작업 결과를 확인할 수 있습니다. 일반 실행 중에는 로그를 수집하거나 파일에 추가하지 않습니다. 진단 시작/종료로 명시적으로 수집을 제어하며, 진단 중의 자동실행 설정 기록만 %LOCALAPPDATA%/EasyBlueNext/startup.log에 남깁니다. 회사 정책이나 작업 스케줄러 서비스 문제는 성공으로 표시하지 않습니다.

검증: 순수 작업 정의와 기존 코어 검사, Windows용 컴파일, 설치파일 추출 및 해시 비교. 실제 Windows COM 등록, 로그아웃/로그인, 배터리, 강제 종료 후 재시도, 설치/제거는 이 Linux 환경에서 실행하지 못했습니다.

## 추가 변경
- 라이트/다크 공통의 6px 둥근 스크롤 핸들, 12px 조작 영역, 호버/드래그 상태. 기기 관리와 진단, 텍스트 입력에 공통 적용.
- 진단 기본 꺼짐, 시작/종료 버튼, 최대 500개 기록, 명시적 저장. 진단 종료 후 이전 비동기 콜백은 세션 번호로 제외. 클립보드 내용은 기록하지 않음.
- 업데이트 시 새 버전 종료 IPC로 정상 종료 요청 후 저장 완료와 프로세스 종료를 최대 30초 대기. 0.3.1 이하에는 IPC가 없어 사용자에게 장치 작업 완료 확인 후 이전 버전 종료. 안전 종료를 지원하는 새 버전은 대기 초과 시 강제 종료하지 않음. 다른 폴더의 앱은 임의 종료하지 않음.
- 원본 0x4B82E0 특수키 목록과 0x410FE0의 2C/2D 명령 확인. F1~F12의 4개 그룹과 이름, 활성 그룹, 기본 F키 복원 제공. 전환 단축키 우선. 키 해제도 응급 복귀 원장에 포함.
- 클립보드 텍스트 보내기 및 선택적 Ctrl+V 전송. 대상 OS에 따른 전환 키 기본값, US/한국어 두벌식, 초기 한/영 상태, 입력 속도 설정. 한글 자모·완성형 분해, CRLF 정규화, 전체 사전 검사, 20,000자 제한, Esc/PC 복귀로 취소. 이모지·이미지·서식·프랑스/독일 배열 미지원. 대상의 키보드 배열, 입력 언어 및 Caps Lock 상태를 맞춰야 함.
- 자동 전환 경계 판정과 대기 동작은 사용자 요청에 따라 유지. USB 미연결 대기 재검색만 추가.

기존 154개와 추가 28개를 포함한 코어 검사 182개 통과. 실제 Windows의 신규 설정 UI, 자동실행 등록/로그인, 업데이트 프로세스 종료, Bluetooth 특수키/한글 전송은 아직 현장 확인이 필요함.

기기 전환 공통 토스트: 연결 중 브리딩, 성공 1.8초, 실패/취소 5초 표시. 연결 명령 이전부터 입력 활성화까지 10초 취소 토큰 적용. PC 복귀/종료로 진행 중 요청 취소. 토스트는 비활성·클릭 통과 창이며 트레이/단축키/자동 전환 경로가 공통 사용합니다. 타임아웃 및 오류 시 PC 입력을 유지합니다.
