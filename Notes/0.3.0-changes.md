# 0.3.0 준비본

- 페어링 버튼은 상태 조회/이전 취소 처리 중 누른 요청을 유지한다. 반복 클릭으로 중복 시작하지 않는다. 창 클릭 시 활성화만 하고 원래 클릭을 버리는 동작을 방지한다. 포커스 테두리 두께 변경으로 인한 버튼 레이아웃 이동도 제거했다.
- 기기 관리860x640, 배치 영역340px. 기기 목록의 내부 ScrollViewer와 높이 제한을 제거하고 전체 페이지 하나만 스크롤한다. 기본 글꼴13은 유지한다.
- 동글 이름 UI는 PC에 저장되는 별칭이 아니라 실제 Bluetooth 장치 이름을 변경한다. 원본439C20 →419210 →41AF10 경로를 재검토했다. Flash 헤더, usersaver 서명/버전, Bluetooth 서명/버전을 확인하고 주소를 동적으로 얻는다. 해당 EEPROM 이름 필드에만 변경을 적용한다. 대상64바이트 페이지를 먼저 %LOCALAPPDATA%/EasyBlueNext/Backups에 저장하고 다른 바이트를 유지하며, 쓰기 직후 전체 페이지를 재읽어 비교한다. 인식하지 못하는 구조/백업 실패/범위 오류는 쓰지 않는다. 현재 안전하게 인코딩할 수 있는 영문·숫자·기호1~31자만 지원한다. 저장 과정에서 표준 입력은 PC로 복귀하고 완료 후 제어 세션을 복구한다. 휴대폰에 저장된 이전 Bluetooth 이름 캐시는 별도다.
- LEDOnOff 원본 모드에서 off=3800, on은 상태별3888/38A8/388B 및 페어링3889. 설정은 저장하고 다음 세션/전환에도 유지한다.
- 일반 설정의 Windows 시작 시 실행은 현재 사용자 Run 키에 인용된 실제 EXE 경로와 --background를 등록한다. 실행 시 창을 트레이로 보낸다. 설치 시에도 선택 가능하다.
- 마우스 가속과 스크롤 배율을 추가했다. 원본 임계값/특수키 설정 전체의 완전한 복제라고 주장하지 않는다. Original-settings-inventory.md 참조.
- NSIS 설치 EXE: 관리자 권한 없이 LocalAppData/Programs/EasyBlueNext에 설치. 시작 메뉴, 선택적 바탕화면, 앱 제거 등록. 실행 중인 앱은 자동 강제 종료하지 않고 트레이에서 종료하도록 안내. 제거해도 사용자 설정과 동글 백업은 유지한다.
- 핵심 검사154개 통과. Windows 네이티브 실행/실제 EEPROM 이름 변경과 NSIS 설치·제거는 Linux에서 실행 확인하지 못했다. 실기 검증 전 준비본이다.

원본 업데이트 패키지의 BCM-232_A/M/K/C.BIN 헤더도 추가 대조했다. Bluetooth 설정 서명은 파일+0, 버전00010000, 이름 주소14593(0x3901), 용량31로 일치했다.31바이트를 그대로 저장하는 원본 동작을 반영하고 이름 필드 밖에 종료 문자를 추가하지 않는다. 원본 펌웨어 파일은 저장소/설치파일에 포함하지 않는다.
