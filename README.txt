EasyBlue Next 0.3.3 — 기능 통합 후보본 / Windows x64
2026-10-21

설치
- EasyBlue-Next-0.3.3-Setup.exe를 실행하면 현재 사용자에게 설치됩니다.
- 시작 메뉴와 앱 제거 항목을 등록하며, 시작 시 실행/바탕 화면 바로 가기를 선택할 수 있습니다.
- 기존 버전을 트레이에서 종료하고 설치하세요. 설정과 동글 이름 백업은 제거 후에도 남습니다.

포터블 실행
1. 기존 EBTiny.exe와 이전 EasyBlue 미리보기를 종료합니다.
2. ZIP 전체를 새 폴더에 풀고 EasyBlue.Desktop.exe를 실행합니다.
   .NET 런타임을 포함하므로 별도 .NET 설치는 필요 없습니다. 동봉 DLL도 보관하세요.
3. 인터페이스 버전 확인과 제어 세션·기본 설정 초기화를 마친 뒤 USB 연결 및 프로토콜 확인 후 동글에 저장된 기기가 표시됩니다.
   기존 EBTiny가 실행 중이면 동시 제어를 막고 종료 안내를 표시합니다.

화면
- 기본 창860x640, 기본 본문13. 내부는 작은 버튼과 차분한 색으로 변경했습니다.
- 기기 관리가 첫 화면입니다.
- 일반 설정 안에 시스템/라이트/다크 테마와 글자 크기가 있습니다.
- 작은 토글28x16, 실제 클릭 영역40x28.
- 배치 영역340px, 등록 기기를 포함한 기기 관리 페이지 전체를 하나로 스크롤합니다.

페어링
- 0.2.2는 원본의 EB00/8000 버전 확인과 EB01/7FFF 제어 세션 초기화 누락을 보완했습니다.
- 새 연결에서 준비 상태를 최대 약3초 확인합니다. 전체 초기화 제한은8초입니다.
- 취소/시간 만료 시에는 원본처럼 제어 세션을 한 번 재초기화합니다. 페어링 재시도는 아닙니다.
- 기기 관리 우측 상단의 '새 기기 페어링'을 누릅니다.
- 표시 모드3889가 명시적으로 거부되어도 원본과 같이 실제 페어링 펄스23C0/23C1을 각각1회 보냅니다.
  USB 시간 초과나 실제 페어링 명령 거부는 즉시 중단합니다. 자동 재시도는 없습니다.
- 실패/취소/시간 만료 후에는 주기적 상태 조회와 자동 전환도 멈춥니다.
  사용자가 새 페어링 또는 새로고침을 눌러야 재개합니다.
- 동글 응답을 확인한 뒤 대기 창이 열립니다.
- 휴대폰/태블릿 Bluetooth 설정에서 EasyBlue를 선택하고 연결 요청을 수락합니다.
- 휴대폰이 PIN 입력을 요구하면 대기 창에서 숫자 PIN을 입력하고 전송합니다.
- 새 주소가 저장되고 연결 상태가 확인되면 완료로 표시합니다.
- 최대60초 대기. 창을 닫으면 대기 취소를 요청합니다.
- 페어링 저장 한도4개. 설정 기기 설정에서 확인 후 삭제할 수 있습니다.

배치와 화면 크기
- PC 모니터 위치/해상도/회전은 Windows에서 읽습니다.
- 모니터 인치는 자동 검출하지 않습니다. 기본27인치이며 '화면 크기'에서 변경하세요.
- 기기설정에서 이름, 인치, 해상도, 세로/가로를 변경합니다.
- 폰 기본7인치. 태블릿은설정에서12인치와 실제 해상도로 변경하세요.
- 물리 인치와 종횡비를 같은 배율로 그립니다. 작은 기기는 바깥 이름을 잡아 이동할 수도 있습니다.
- 드래그 후 가장자리가 가까우면 붙습니다. 상/하/좌/우와 여러 PC 모니터를 지원합니다.
- 모서리 한 점 접촉이나 떨어진 배치는 자동 경로가 아닙니다.
- 자동 전환 상태 안내에 꺼짐/일시 중지/연결 경로 없음/경로 수를 표시합니다.
- 표시 크기에 맞춰 약10px 이내에서 기기 경계가 붙도록 스냅을 보완했습니다.
- 붙은 구간을 파란색으로 표시합니다. 다른 폰/태블릿과 붙여 경로를 이을 수도 있습니다.
- 떨어진 기기도 전환 버튼/단축키로 사용할 수 있습니다.
- 배치와 이름은 동글 페어링 정보와 별도로 저장하며, 기기 주소로 연결합니다.

입력 전환
- 행의 '전환' 또는 기기 관리에서 직접 지정한 단축키를 사용합니다. 고정 Ctrl+Alt+1~4는 제거했습니다.
- 저장된 대상에 연결 요청 후 현재 연결 주소를 확인해야 PC 입력을 가로챕니다.
- 가장자리 자동 전환을 켜면, 맞닿은 구간에서 대기 시간0.2~3초 후 인접 기기로 전환합니다.
- 선택되지 않은 등록 기기로도 연결을 시도합니다. 연결 실패 시 PC 입력을 유지하고,
  해당 가장자리에서 벗어나기 전까지 같은 시도를 반복하지 않습니다.
- PC 모니터 사이는 원래 Windows 마우스 이동을 유지합니다.
- 폰에서 반대 경계로 이동해 머물면 PC 또는 인접 기기로 전환합니다.
- 입력 설정에서 마우스 속도와 한/영 키 Ctrl+Space 전송을 조정할 수 있습니다.
- 기본 PC 복귀: Ctrl+Alt+F12. 기본 마지막 기기 연결: Ctrl+Alt+F11.
- 입력 설정의 해당 칸을 클릭하고 원하는 조합을 누르면 즉시 저장합니다.
  Ctrl/Alt/Win 조합 또는 F1~F24 단독 키를 사용할 수 있습니다.
- PC 복귀와 마지막 기기 연결을 같은 키로 지정하면 PC에서는 마지막 기기로, 기기에서는 PC로 전환합니다.
- 기기 관리의 각 기기 이름 아래 단축키 버튼에서 조합 지정/해제/저장을 할 수 있습니다.
  다른 기기 또는 전역 단축키와 중복되는 기기 단축키는 저장하지 않습니다.
- 하단 PC 복귀 버튼에는 현재 설정된 단축키가 표시됩니다.
- 마지막으로 연결에 성공한 기기는 앱을 다시 실행해도 기억합니다.
- 경계 대기 중 PC 화면에 남은 초와 대상 이름, 진행 막대, 브리딩 효과를 표시합니다.
  폰→PC 복귀 시에도 PC의 연결 경계에 표시합니다. 폰 화면 자체에는 표시하지 않습니다.
  영역을 벗어나거나 드래그/전환을 시작하면 표시를 취소합니다. 안내창은 클릭/포커스를 받지 않습니다.
- 오류 후 일시 중지되었다면 자동 전환을 껐다 켜거나 새로고침하여 재개할 수 있습니다.
- 입력 큐 지연/USB 오류/모니터 구성 변경 시에도 PC 입력 복구 경로를 넣었습니다.
- 키 입력 훅 안에서 USB 응답을 기다리지 않습니다. 마우스 이동은 합산 후 분할 전송합니다.

트레이와 종료
- X 또는 최소화: 창을 숨기고 PC 입력으로 복귀합니다. 트레이에서 계속 실행됩니다.
- 트레이 아이콘 더블클릭 또는 'EasyBlue 열기': 창 복원.
- 트레이 메뉴에서 PC 복귀 / 마지막 기기 연결 / 완전 종료를 선택합니다.
- 완전 종료는 창을 즉시 숨기고, 최대3초 동안 입력 해제를 시도한 뒤 종료합니다.
- 이미 실행 중일 때 EXE를 다시 실행하면 기존 창을 복원합니다.
- 원본 EXE에서 추출한 아이콘과 형태를 유지한 벡터 재제작 아이콘을 소스에 포함했습니다.

동글과 시작 설정
- 기기 관리의 동글 이름 변경에서 실제 Bluetooth 이름을 읽고 변경합니다.
- 영문·숫자·기호 최대31자. 원본 페이지 백업 후 저장하고 재읽어 검증합니다.
- 백업 위치: %LOCALAPPDATA%/EasyBlueNext/Backups. 휴대폰의 이전 이름 캐시는 별도입니다.
- 일반 설정에서 LED 켜기와 Windows 시작 시 트레이 실행을 선택합니다.
- 원본 설정 이식 범위와 아직 남은 특수키·클립보드 항목은 original-settings.md를 확인하세요.

지원 및 검증 범위
- 독립 USB 통신은 VID1D54/PIDB002 제어 인터페이스를 대상으로 구현했습니다.
  B001은 현재 지원하지 않습니다.
- 원본의 페어링 버튼, 저장 대상 연결, 페어링 삭제, PIN 입력 호출 경로와 어셈블리를
  대조했습니다. 기존 문서의 D001/D002 의미 추정은 다시 대조하여 사용했습니다.
- 상세한 재분석 근거, 함수 주소와 한계는 동봉 protocol-audit.md에 있습니다.
- B002 프레임, 입력 초기화, 페어링/PIN/연결/삭제 순서, 해상도별 배치/스냅/대기,
  키 해제 복구, 설정 저장에 대한 핵심 검사176개 통과.
- WPF Windows 크로스 빌드와 게시 성공. 이 Linux 환경에서는 Windows UI를 실행하거나
  실제 USB/Bluetooth 장치에서 동작을 확인하지 못했습니다.
  따라서 실기 동작 확인이 남은 통합 후보본이며 정상 동작 확정판이 아닙니다.
- 휴대폰 실제 커서 좌표를 읽는 기능은 없습니다. PC에서 보낸 이동량으로 위치를 추정합니다.
  폰의 마우스 가속/터치/실제 해상도와 차이가 생길 수 있습니다. 배치 지정만으로 실제
  커서 위치까지 정확히 알 수는 없습니다. 화면 해상도와 속도를 맞추고 사용해 주세요.
- PC 클립보드 텍스트 전송과 원본 특수키 그룹 전체는 아직 이식하지 않았습니다. 일반 설정에서 기존 설정 앱으로 연결할 수 있습니다.
- 기기 행의 '설정'에서 표시 이름을 직접 수정하고 저장할 수 있습니다.
- 'Windows에 저장된 기기 이름 가져오기'는 PC Bluetooth 캐시를 읽습니다.
  동글 자체에만 페어링되어 PC에 이름이 없는 기기는 직접 입력해야 합니다.
  동글의 원격 이름 조회 및 폰 자체 이름 변경은 구현하지 않았습니다.
- 연결됨은 현재 주소 조회로 확인한 대상입니다. 등록됨은 저장된 대상이며 온라인 확인을 뜻하지 않습니다.

오류가 날 때
- '진단'에서 진단 저장을 누르세요. 관리 요청/응답의 헤더·길이와 오류를 기록합니다.
  키 입력 내용, PIN, 기기 주소 payload는 진단에 기록하지 않습니다.
- 통신 오류 뒤에는 새로고침으로 장치를 다시 엽니다.
- 기존 앱으로 돌아가려면 트레이 메뉴에서 새 앱을 완전히 종료하거나 진단의 기존 앱 실행 버튼을 사용합니다.
  원본과 정상 동작하던 r3 패키지는 변경하지 않았습니다.

설정 저장
%LOCALAPPDATA%/EasyBlueNext/preferences.json
이전 미리보기의 큰 기본 글꼴 설정은13으로 이관합니다.

Windows .NET10 SDK: Build-Windows.ps1

소스 폴더는 Rewrite 아래입니다. 별도 원본 EBTiny.exe/KMHook.dll 없이 실행하도록 구현했습니다.

0.3.2: 트레이 우클릭 메뉴에서 등록된 기기의 이름, 연결 상태, 단축키를 확인하고 클릭하여 연결·입력 전환할 수 있습니다. 등록됨은 온라인 여부를 보장하지 않습니다.

0.3.3 자동실행과 연결 안내
- 예약 작업 대신 현재 사용자의 Windows 시작프로그램 폴더에 EasyBlue Next.lnk를 등록합니다.
- 실행파일, --background 옵션, 작업 폴더를 저장하고 다시 읽어 검증합니다. 관리자 권한이나 비밀번호를 요구하지 않습니다.
- 기존 예약 작업과 EasyBlueNext Run 항목을 정리합니다. 정리에 실패하면 일반 설정에 표시합니다.
- Windows 시작 앱 버튼으로 OS의 실행 허용 여부를 확인할 수 있습니다. 회사 정책이나 Windows에서 비활성화하면 실행되지 않을 수 있습니다.
- 연결 중 토스트는 화면 오른쪽 아래에 최소0.7초 표시됩니다. 실제 입력 전환을 늦추지 않습니다. 성공2.6초, 실패6초 표시합니다.
- 기기 전환 제한10초와 기존 자동 전환 판정은 유지합니다.
- 진단은 진단 시작을 누른 동안만 기록합니다.
- 특수키 그룹과 클립보드 설정은 입력 설정에서 사용할 수 있습니다. 영문/한국어 두벌식 텍스트를 지원하며 이모지/이미지/프랑스·독일 배열은 지원하지 않습니다.
- 코어 검사176개 통과. 실제 Windows 시작프로그램 등록/로그인과 UI는 이 Linux 환경에서 검증하지 못했습니다.
